# 예제 프로젝트

[Rice.exe](../../../Rice.exe)를 실행한 뒤 **File → Open Project**에서 프로젝트를 열고 **Play**를 누릅니다.

| 프로젝트 | 내용 |
|---|---|
| [Grass1000.rice](../../../Projects/Grass1000/Grass1000.rice) | 잔디 텍스처를 입힌 큐브 1,000개의 렌더링 성능을 확인합니다. [사용법](Grass1000/README.md) |
| [Steve.rice](../../../Projects/Steve/Steve.rice) | 움직이는 물체의 경계와 포인트 광원 그림자를 확인합니다. [사용법과 녹화 영상](Steve/README.md) |

**Project → Project / Export → Build standalone game**에서 만든 게임 EXE는 다른 폴더나 PC로 복사해 직접 실행할 수 있습니다.
