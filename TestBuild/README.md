# 기존 에디터 보존본

프로젝트 없는 시작 화면을 도입하기 직전의 실행 파일과 프로젝트를 보존했습니다.

- **RiceSandbox.exe**: 기존 에디터. 옆의 `Project` 폴더를 자동으로 엽니다.
- **Project/project.rice**: Grass1000을 활성 씬으로 가진 프로젝트. 최상단의 새 에디터에서 **File → Open Project**로도 열 수 있습니다.
- **RicePlayer.exe**: 이 프로젝트를 바로 실행하는 독립 플레이어.
- **SeedAssets**, **docs**, **EditorLayout.ini**, **DLL**: 기존 실행본의 리소스와 레이아웃.

진단 로그와 백업·임시 파일은 제외했습니다. 최상단 빌드 스크립트는 이 보존본을 변경하지 않습니다.
